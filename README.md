# Modusistema — Ecosistema Digital Corporativo y Gestión de Preventas

Este repositorio alberga la documentación estratégica, análisis de viabilidad técnica y desarrollos digitales para **Modusistema, C.A.** (Distribuidor Autorizado exclusivo de **MillerKnoll** en Venezuela).

---

## 📄 Guía Ejecutiva de Preventas e Importaciones

Estrategia comercial y arquitectura de software para resolver los 4 dolores críticos en importaciones marítimas de largo tránsito (90 a 180 días):

1. **Radar de Inventario Flotante:** Seguimiento por contenedor, B/L, naviera y cálculo reactivo en base de datos sin sobreventas.
2. **Motor Anti-Apartados Fantasma:** Auto-liberación de inventario (*Auto-Drop*) en 72 horas si no se valida el anticipo bancario del 30% al 50%.
3. **Cálculo de Costo Landed Dinámico:** Prorrateo paramétrico por volumen ($CBM$) y peso ($KG$) de fletes, seguros y aranceles CIF para blindar el margen neto antes de zarpe.
